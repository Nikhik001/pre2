PRE-BOARD KI BARBAADI™

1. Extract the entire ZIP to a folder.
2. Keep index.html, quiz.html, reels.html, credits.html, and the media folder together.
3. Open index.html in Chrome or another modern browser.
4. Use the top navigation to move between pages.
5. Videos are local files inside media/. The end-credit song plays after you press the song button (browsers block audio autoplay until a click).
